# Mini Soccer

A simple browser-based soccer game built with HTML, CSS, and JavaScript.

## How to play

- Open `index.html` in a browser.
- Use `W` / `S` or `↑` / `↓` to move the home team.
- The computer controls the away team.
- Score goals before the other side.

## Files

- `index.html` – game layout
- `style.css` – pitch styling and HUD
- `script.js` – game logic and rendering

## Run locally

You can either:

1. Double-click `index.html`, or
2. Serve the folder with a local web server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Notes

This is a lightweight arcade game and can be expanded with sound effects, multiplayer controls, or a richer UI.
